## Expected behavior and ten pending executable cases

The numerical weights come from the R32 request. The current integration
contract does not name the five factors or their aggregation function, so the
examples use F1 through F5 in that order rather than inventing domain names.
For comparable factor scores on a 0–100 scale, the intended reweighting oracle
is `sum(w[i] * s[i]) / sum(w[i])`, summed over available eligible factors only.
Zero is a valid score; null is missing. Empty coverage is explicitly unavailable.
If the implementation uses 0–1 internal values, apply the documented scale
conversion at its boundary.
