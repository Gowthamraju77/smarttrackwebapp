## Executable-check plan after implementation is available

These are pending checks, **not passes**. Use only synthetic fixtures and the
actual documented generator interface; do not invent an adapter to absent code.

1. Same seed and parameters produce the same complete records across two fresh
   processes, including timestamps, record/device/boot IDs, labels, and metadata.
2. Different seeds affect genuinely stochastic fields while preserving schema
   and scenario guarantees; deterministic scenarios need not vary.
3. An explicit zero seed is honored, and unrelated global RNG use does not
   perturb a seeded call or vice versa.
4. Empty/zero count and a single record have documented behavior and valid output.
5. Negative, fractional, Boolean, nonnumeric, and excessive counts/seeds are
   either rejected clearly or handled according to the documented contract,
   with bounded work and no partially written output on validation failure.
6. Generated valid telemetry has finite numbers, in-range coordinates, valid
   sequence/uptime/time fields, and strict JSON serialization; intentionally
   invalid fixtures are explicitly labeled as such.
7. No-fix, stale-fix, missing IMU, and unsynchronized-clock scenarios, where
   supported, preserve null/unavailable evidence and do not fabricate a fix.
8. Record identity/sequence/boot transitions and intentional retry duplicates
   match their documented scenario rather than silently colliding.
9. Source, fixtures, and runtime inputs demonstrate synthetic provenance without
   reading real private records; generated output retains explicit synthetic
   labeling through dataset/model metadata.
10. Synthetic provenance survives training/artifact handling and cannot yield
    production validation/promotion or a safety-probability claim. Actual held-out
    synthetic metrics, if present, remain labeled synthetic and are not field
    validation.

The applicable contract boundaries are `docs/CONTRACT.md:4`, `:7-9`, `:18`, and
`:25-26`. Ten repetitions of a file-existence check would not test these behaviors
and would not constitute ten end-to-end passes.
