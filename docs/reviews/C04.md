- `firmware/include/ui/types.h:6-24` supplies nine `Page` values, a value-initialized `State`, and four abstract `Canvas` methods. Pages use `inline void render…(Canvas&, const State&)` within `smarttrack::ui`; no page owns network or storage behavior.
- `State` uses validity/availability flags alongside numeric values. `fixAgeMs` is an unsigned integer without an explicit unknown marker; the main adapter must not convert an unknown wire `gps.age_ms` into a fresh zero-age fix. This is an integration requirement, not a demonstrated caller defect while main is absent.
- `State::deviceId`, `responder`, `instruction`, and `fault` are non-owning `const char*` values. Main must keep their storage alive while rendering. `sosAcknowledged` must describe the responder acknowledgment transition, not merely ingest acceptance or link state.
